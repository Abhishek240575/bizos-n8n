# BizOS — AI Operating System for Small Businesses

n8n-based automation backend for invoices, payments, inventory and business reports.

## Stack
- n8n (self-hosted, Docker)
- PostgreSQL (Neon cloud)
- Gemini AI
- Cloudflare Tunnel

## Workflows
- BizOS 01: AI Chat (Hindi/English Q&A)
- BizOS 06: Sale Invoice Creation with Owner Approval
